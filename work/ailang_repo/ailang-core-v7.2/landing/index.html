¿Por qué AILang?

No es solo otro lenguaje. Es un runtime cognitivo completo con tooling profesional.

🔒

Capability Enforcement

--allow filesystem.read --allow ai.query. Todo no autorizado es DENIED por defecto.

🧠

Runtime Cognitivo

brain.ingest(), brain.query(), brain.think() con búsqueda lexical + vectorial + graph.

⚡

5 Backends

Interpreter, VM (1.5-2.3x faster), AIR, LLVM JIT, WASM. Multi-backend selection automática.

📐

Pipeline HIR/MIR/AIR

AST → HIR → MIR (SSA + optimizaciones) → AIR (tipado con effects + capabilities). Como LLVM pero para AILang.

🔧

Tooling Completo

LSP (14 métodos), DAP (step over/into/out), formatter, linter, profiler, package manager, fuzzer, benchmarks.

🧪

Tensor + Crypto

Tensor con autograd (matmul, softmax, relu), crypto API (Ed25519, AES-256-GCM, SHA-256, HKDF, Fernet).

🎯

Type System Gradual

Types opcionales con inference, narrowing, y generics (List[int], Dict[string, int]).

📦

Package Manager

ailang pkg init/install/publish/search con .ailpkg (tar.gz + SHA-256 + Ed25519 signing).

🌐

CI Multiplataforma

GitHub Actions: 3 OS × 3 Python = 9 jobs. Fuzzing + property-based testing en CI.

Instalación

Empieza en 30 segundos

$ pip install ailang-core

Requiere Python 3.10+. Opcional: cryptography, psycopg-pool, llvmlite, hypothesis

$ python -m ailang doctor # verifica instalación
